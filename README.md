# Website Mirror (HTML Archiver)

A powerful CLI utility written in Rust for archiving the HTML content of websites. It recursively crawls a target site, downloads all HTML pages, and saves them locally.

This tool is the first phase of a larger project to create fully browsable offline website mirrors. Its primary purpose is to discover and save all HTML pages from a site while normalizing all links to be absolute URLs.

## Features

- 🚀 **Fast & Efficient**: Built with Rust for high performance and concurrent crawling.
- 📄 **HTML-First Archiving**: Recursively crawls and downloads all HTML pages from a target website.
- 🔗 **Link Normalization**: Automatically converts all links in downloaded HTML files to absolute URLs, preparing the archive for future processing.
- 🔄 **Automatic Resumption**: Crawls can be interrupted and resumed from where they left off.
- 💾 **Persistent State**: All crawl progress, including the download queue, completed files, errors, and ignored URLs, is saved to disk for fault tolerance.
- 🤫 **Ignore Patterns**: Specify regex patterns to exclude certain URLs from being mirrored.
- ⚡ **Concurrent Downloads**: Configurable concurrent download limits.
- 🎯 **Depth Control**: Configurable crawling depth limits.
- 🤖 **Robots.txt Bypass**: Option to ignore robots.txt restrictions.
- 🔒 **SSL Support**: Handles SSL certificates and secure connections.

## How It Works

1.  **Initialization**: Sets up an HTTP client with SSL certificate handling.
2.  **State Management**: Loads or creates a persistent crawl state file at `output_dir/.mirror/state.json`. If a previous state is found, the queue is loaded for resumption.
3.  **Crawling**: Starts from the base URL and discovers linked pages, adding them to a priority queue.
4.  **HTML Download**: Downloads all discovered HTML pages. A smart cache prevents re-downloading pages that have already been processed.
5.  **Link Extraction**: Parses downloaded HTML to find more links to add to the queue.
6.  **State Persistence**: Continuously saves progress to the `state.json` file, tracking every URL that is queued, downloaded, errored, or ignored.

## 🗺️ Project Roadmap

This tool represents Phase 1 of a three-phase project to create fully-featured offline website mirrors.

### Phase 1: HTML Archiver (Complete)

The current tool. It crawls a website to discover and download all of its HTML pages. It creates a comprehensive record of the site's structure and content in a persistent state file (`state.json`).

### Phase 2: Resource Downloader (Planned)

A future tool or command that will read the `state.json` file generated by the HTML Archiver. It will be responsible for downloading all non-HTML assets required by the archived pages (e.g., CSS, JavaScript, images, fonts).

### Phase 3: Offline Site Generator (Planned)

The final phase will be a tool that processes the downloaded HTML and resources. It will rewrite all links to be relative, creating a self-contained, locally browsable version of the website that works perfectly offline.

## 🔄 Resumption & Fault Tolerance

The mirror tool supports full crawl resumption with persistent state management.

### Automatic Resume

- If a crawl is interrupted (Ctrl+C, power failure, crash), simply run the same command again.
- The tool automatically detects the existing state file at `output_dir/.mirror/state.json`.
- Crawling continues from exactly where it left off, with no duplicate downloads.

### Persistent State Structure

The state file tracks the entire crawl process. Here is an example of its structure:

```json
{
  "queue": [],
  "processing": [],
  "downloaded": {
    "https://example.com/": {
      "local_path": "example.com/index.html",
      "resource_type": "Link",
      "size_bytes": 1256,
      "downloaded_at": "2025-10-10T12:10:27.000000-07:00"
    },
    "https://example.com/about": {
      "local_path": "example.com/about.html",
      "resource_type": "Link",
      "size_bytes": 512,
      "downloaded_at": "2025-10-10T12:10:28.000000-07:00",
      "source_url": "https://example.com/"
    }
  },
  "errored": {
    "https://example.com/broken-link": {
      "error_message": "HTTP 404 Not Found for https://example.com/broken-link",
      "attempted_at": "2025-10-10T12:10:29.000000-07:00",
      "resource_type": "Link",
      "source_url": "https://example.com/"
    }
  },
  "ignored": {
    "https://example.com/login": {
      "reason": "Matched ignore pattern",
      "ignored_at": "2025-10-10T12:10:30.000000-07:00",
      "resource_type": "Link",
      "source_url": "https://example.com/"
    }
  }
}
```

### Benefits

-   **No Lost Work**: Every URL is tracked persistently.
-   **Crash Recovery**: "Processing" URLs automatically return to the queue on restart.
-   **Efficient Resume**: No re-downloading or re-processing of completed work.
-   **Debug-Friendly**: The JSON state file is human-readable for troubleshooting.

## Installation

### Prerequisites

-   Rust 1.89.0 or later
-   Cargo (comes with Rust)

### Build from Source

1.  Clone or download this repository.
2.  Navigate to the project directory.
3.  Build the project:

```bash
cargo build --release
```

4. The binary will be available at `target/release/website-mirror`.

## Usage

### Command Line Options

| Option | Short | Description | Default |
|---|---|---|---|
| `--url` | | Target website URL (required) | - |
| `--output-dir` | -o | Output directory for mirrored files | `./mirrored_site` |
| `--max-depth` | -d | Maximum crawling depth | `3` |
| `--max-concurrent` | -c | Maximum concurrent downloads | `10` |
| `--ignore-robots` | -r | Ignore robots.txt restrictions | `false` |
| `--ignore-patterns`| | Exclude URLs matching regex patterns. Can be specified multiple times. | `None` |
| `--only-resources` | | Mirror only specific resource types. Currently, `html` is the only supported type. | `all` |
| `--user-agent` | -u | Custom user agent string | `WebsiteMirror/1.0` |
| `--follow-redirects`| -f | Follow HTTP redirects | `true` |
| `--timeout` | -t | Request timeout in seconds | `30` |

### Usage Examples

```bash
# Basic HTML crawl
./website-mirror https://example.com

# Crawl with custom output directory, depth, and concurrency
./website-mirror https://example.com -o ./my_archive -d 5 -c 20

# Exclude URLs containing 'login' or 'forum'
./website-mirror https://example.com --ignore-patterns ".*login.*" --ignore-patterns ".*forum.*"

# High-performance crawl
./website-mirror https://large-site.com --max-concurrent 50 --timeout 60
```

## 📁 File Structure

The output directory will contain all the downloaded HTML files and the crawl state.

```
mirrored_site/
├── .mirror/
│   └── state.json          # Persistent crawl state (queue, downloaded, errored, ignored)
├── example.com/
│   ├── index.html
│   └── about.html
└── blog/
    ├── index.html
    └── post-1.html
```
